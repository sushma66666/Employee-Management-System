# Employee Management Dashboard

A complete **Java Full Stack CRUD Application** developed as a final year B.Sc. Computer Science project.

## 🚀 Tech Stack Used
* **Backend:** Java, Maven, JDBC
* **Frontend:** HTML5, CSS3, JavaScript (Bootstrap for responsive UI)
* **Database:** MySQL
* **IDE:** Eclipse

## 💡 Key Features
* Clean and interactive **Employee Dashboard UI**.
* Complete **CRUD Operations** (Create, Read, Update, Delete Employee records).
* Structured Maven project architecture.
